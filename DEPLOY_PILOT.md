## Google Cloud setup

- Enable **Google Sheets API** in the Cloud project.
- Create a Service Account.
- Create a JSON key for that account.
- Open the Mack ENADE Google Sheet and share it with the Service Account `client_email` as **Editor**.
- Keep the Sheet private; do not use "Anyone with the link".

## Google AI Studio / Cloud Run

- Add the environment variables/secrets above.
- Publish the full-stack app.
- Cloud Run's `PORT` is read automatically from `process.env.PORT`.

## Authentication model

- User enters `institutional_email` + `access_code`.
- Both must exist in `students` or `professors`.
- `login_active` must be TRUE.
- Student also requires `pilot_eligible = TRUE` when the field is present.
- Session is stored in a signed `HttpOnly`, `SameSite=Lax` cookie.
- No Microsoft/Entra variables are required.
